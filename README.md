# Baojie Wang — Academic Website

Static source for Baojie Wang's English academic homepage, focused on agentic coding and agent self-evolution.

## Local preview

```bash
python -m http.server 8000
```

Open `http://localhost:8000/`.

## Public content and privacy

The site intentionally publishes only the academic information shown on the homepage. It contains no portrait, phone number, political affiliation, unredacted résumé/CV, analytics, forms, or first-party tracking cookies.

The page requests Google Fonts at load time and requests the arXiv HTML preview only after the RoleMotion preview is opened. External services may receive ordinary network metadata.

## Asset attribution

Institution marks identify affiliations only and do not imply endorsement. Sources are documented in the development repository; all marks and the RoleMotion preview used by the page are stored locally under `assets/images/`.
